# Games

One settings page covers all of Bradycat's mini-games and fun features. Configure under **Settings > Games**.

<deflist type="medium">
    <def title="Minecraft">
        Enable or disable the Minecraft player and server lookups (<code>/minecraft</code>). See <a href="Minecraft.md"/>.
    </def>
    <def title="Economy, Casino, Games">
        Three independent switches. <b>Economy</b> turns on the coin system (<code>/coins</code>, <code>/pay</code>, <code>/cointop</code>, <code>/reward</code>). <b>Casino</b> unlocks <code>/slots</code> and <code>/coinflip</code> (requires Economy). <b>Games</b> is the general switch for the mini-games.
    </def>
    <def title="Weekly Casino Leaderboard">
        Enable <code>/casinotop</code>, the ranking of this week's casino profits. It starts over every Monday at midnight. The channel field is not used yet. Closed beta.
    </def>
    <def title="Tic-Tac-Toe">
        Enable/disable, and pick the channel it's playable in. Closed beta, see <a href="Tic-Tac-Toe.md"/>.
    </def>
    <def title="Guess the Number">
        Enable/disable, and pick the channel. See <a href="Setup-Guess-Number.md"/>.
    </def>
    <def title="CityGuessr (GeoGuessr-style)">
        Enable/disable. Closed beta, see <a href="CityGuessrChild.md"/>. The channel field is not used yet - CityGuessr can be played in every channel.
    </def>
    <def title="Counting Game">
        Enable/disable, pick the channel, and configure: a role assigned when someone breaks the count, whether calculations like <code>2*5+1</code> are allowed, and whether only numbers are accepted (turning this off allows normal chat messages in the channel without them counting as mistakes). More options like the price of a save are in <code>/countingsettings</code>, see <a href="Counting-Game.md"/>.
    </def>
</deflist>
