# /enablefeature

These commands usually contain the features that have to set up their own command or simply have to be activated. Enter <code>/enablefeature</code> and pick the feature in the <code>setting</code> option.

| Setting | What it switches on |
|---|---|
| Economy System | Coins, `/coins`, `/pay`, `/cointop`, `/reward` - see [Economy System](Economy-System.md) |
| Casino System | `/slots`, `/coinflip` - see [Casino Games](Casino-Games.md) |
| Games | General switch for the mini-games |
| Ticket Claim | Claiming in the [ticket system](Setup-Ticket-System.md) |
| CityGuessr | `/cityguessr` - see [CityGuessr](CityGuessrChild.md) (closed beta) |
| Twitch | Live announcements - see [YouTube and Twitch](YouTube-and-Twitch-Command.md) |
| YouTube | Currently not available |
| Laut.FM Notification | Currently not available |
| Qout Messages | Previews of message links - see [Quote Messages](Qout.md) |
| CountingGame | The counting channel - see [Counting Game](Counting-Game.md) |
| TopWords | `/topwords` - see [Top Words](Top-Words.md) (closed beta) |
| TicTacToe | `/tictactoe` - see [Tic-Tac-Toe](Tic-Tac-Toe.md) (closed beta) |

<note>
<p>You need the <b>Administrator</b> permission. Closed beta features can only be switched on for servers that take part in the beta (shown as <b>Premium</b> in the dashboard).</p>
</note>

## /disablefeature
Switches a feature off again. It works for everything above and also for the features you set up with <a href="setupcommands.md">/setup</a>: Welcome, Guess Number, Guild Action, Level System, Suggestion System, Giveaway System, Verify System, Ticket System and Minecraft Support.

Your settings (channels, roles, ...) are kept when you switch a feature off. To switch a <code>/setup</code> feature on again, run its setup again or use the switch in the dashboard.

<tip>
<p>All of these switches are also available in the <a href="Guild-Settings-and-Modules.md">dashboard</a>.</p>
</tip>
