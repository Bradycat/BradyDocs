# Welcome Messages

Greets new members automatically when they join. Configure under **Settings > Welcome**.

- **Enable/disable** the module.
- **Channel** - where the welcome message is posted.
- **Message** - built with the same visual message editor used in <a href="Create-Message-Panel.md"/>, so you can include embeds, images and formatting, not just plain text. Write <code>&percnt;username&percnt;</code> where the new member should be mentioned.

If you don't design your own message, the bot posts a short "New member!" message with a random greeting.

See also <a href="Setup-Welcome.md"/>.
