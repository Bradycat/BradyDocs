# Features

<p>Here you can find out about all the functions of our Discord bot and how they work.</p>

<deflist type="medium">
    <def title="Minecraft">
        Look up Minecraft players and servers. See <a href="Minecraft.md"/>.
    </def>
    <def title="Giveaway">
        Host giveaways with requirements, several winners and rerolls. See <a href="Giveaway.md"/>.
    </def>
    <def title="Custom Commands">
        Your own slash commands with your own answers. See <a href="Custom-Commands.md"/>.
    </def>
    <def title="Private Voice Channels">
        Members get their own voice channel and decide who can join. See <a href="Private-Voice-Channels.md"/>.
    </def>
    <def title="Utility Commands">
        <code>/userinfo</code> and <code>/clear</code>. See <a href="Utility-Commands.md"/>.
    </def>
</deflist>

<tip>
<p>Features you set up with a command are described under <a href="How-to-setup.md"/>: the <a href="setupcommands.md">/setup</a> features (level system, tickets, verify, ...) and the <a href="enablefeature.md">/enablefeature</a> features (economy, casino, counting, ...).</p>
</tip>
