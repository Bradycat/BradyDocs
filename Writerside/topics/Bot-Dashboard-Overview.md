# Bot Dashboard

The Dashboard is the general web panel for managing Bradycat on your server - separate from <a href="What-is-Team-Panel.md">Team-Panel</a>, which is the closed-beta collaborative workspace. The Dashboard is available to everyone right now.

<procedure title="Getting to your server's dashboard">
    <step>
        <p>Log in at <a href="https://beta.bradycat.de">beta.bradycat.de</a> with Discord.</p>
    </step>
    <step>
        <p>Pick your server from the list. Only servers where you have Discord admin permissions and where the bot is present show up here.</p>
    </step>
</procedure>

<note>
Everything in the Dashboard checks your actual Discord permissions on that server (via <code>is_user_admin_in_guild</code>) - there's no separate role system to configure like in Team-Panel. If you're an admin on Discord, you're an admin here.
</note>

From your server's dashboard you can:

- <a href="Server-List.md">Manage your Server List entry</a> - the public listing for your Discord server
- <a href="Create-Message-Panel.md">Build and send messages/embeds</a> to a channel without typing a command
- <a href="Guild-Settings-and-Modules.md">Configure bot modules</a> - level system, tickets, welcome messages, giveaways, and more, all through forms instead of slash commands
