# Custom Commands

Create your own slash commands directly from the dashboard, under **Settings > Custom Commands** - a form-based alternative to setting them up via the <a href="Custom-Commands.md">/customcommand bot command</a>.

For each command you define:

- **Name** - what members type after the slash.
- **Response** - the message the bot replies with.
- **Ephemeral** - whether the response is only visible to the person who used the command, or shown to everyone in the channel.
- **Allowed roles** - restrict who can use the command. Leave empty to let everyone use it.

You can add as many custom commands as you need, and remove or edit them the same way.
