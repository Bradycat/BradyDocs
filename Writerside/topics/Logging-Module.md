# Logging

Posts a log message to a channel of your choice whenever something changes on your server. Configure under **Settings > Logging**:

- **Enable/disable** the module.
- **Log channel** - where these messages get posted.
- **Log categories** - choose what gets logged:
  - Server settings
  - Channels
  - Roles
  - Members
  - Voice
  - Emojis and stickers
  - Messages (edited and deleted)
  - Invites

Members joining and leaving are always logged while the module is on.

Use this if you want a paper trail of what happened on your server without checking Discord's own audit log manually. In the bot, this feature is called Guild Actions - see <a href="Setup-Guild-Actions.md"/> for what each category contains.
