# Welcome

<p>The bot greets every new member with a message in a channel of your choice.</p>

<procedure title="Setting it up with /setup welcome" id="welcome-setup">
    <step>
        <p><b>Should the users be welcomed?</b> - answer <code>yes</code>.</p>
    </step>
    <step>
        <p><b>In which channel should the users be welcomed?</b> - mention the channel with <code>#</code>.</p>
    </step>
</procedure>

By default, the bot posts a short "New member!" message with a random greeting that mentions the new member.

<tip>
<p>In the dashboard you can design your own welcome message with text, embeds and images. Use <code>&percnt;username&percnt;</code> where the new member should be mentioned. See <a href="Welcome-Messages-Module.md"/>.</p>
</tip>
