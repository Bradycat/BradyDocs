# GitHub Integration

Connect your team's GitHub repositories to the panel to see pull requests and commits without leaving Team-Panel, and to link that activity directly to your <a href="Boards.md">Boards</a>.

<note>
Needs the <code>github</code> module enabled. <code>read_github</code> lets you view connected repos and their activity; <code>manage_github</code> is needed to connect repositories and to approve or reject actions (like linking a PR to a card).
</note>

## What you get

- A live view of pull requests and recent commits for each connected repository.
- The ability to link a card on a Board to a specific PR or commit, so anyone looking at the card can jump straight to the relevant code.

This is meant as a lightweight bridge, not a replacement for GitHub itself - it's there so your team doesn't have to alt-tab between the panel and GitHub just to check whether that PR got merged yet.
