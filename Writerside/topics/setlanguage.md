# /setlanguage

<p>This sets the language the bot uses on your server. <b>English</b> and <b>German</b> (Deutsch) are available.</p>

<procedure title="Changing the language" id="setlanguage-procedure">
    <step>
        <p>Enter <code>/setlanguage</code> and pick <b>English</b> or <b>Deutsch</b> for the <code>language</code> option.</p>
    </step>
    <step>
        <p>Press <shortcut>Enter</shortcut>. The bot confirms the change - already in the new language.</p>
    </step>
</procedure>

<note>
<p>You need the <b>Administrator</b> permission to use this command.</p>
</note>

<tip>
<p>You can also change the language in the dashboard under <b>Settings</b>, see <a href="Guild-Settings-and-Modules.md"/>.</p>
</tip>
