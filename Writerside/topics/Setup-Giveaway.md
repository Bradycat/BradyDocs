# Giveaway (Only Setup)

<p>This page only covers the setup. How to create and manage giveaways is explained in <a href="Giveaway.md"/>.</p>

<procedure title="Setting it up with /setup giveaway" id="giveaway-setup">
    <step>
        <p><b>Should the giveaway system be activated?</b> - answer <code>yes</code>.</p>
    </step>
    <step>
        <p><b>With which role should you be able to create giveaways?</b> - mention the role of your giveaway managers with <code>@</code>.</p>
    </step>
</procedure>

<note>
<p>Members with the <b>Manage Server</b> permission can always manage giveaways, even without the giveaway role.</p>
</note>

<tip>
<p>You can also set this up in the dashboard, see <a href="Giveaway-Module.md"/>.</p>
</tip>
