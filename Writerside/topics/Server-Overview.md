# Server Overview

Opening a server from your <a href="Personal-Dashboard.md">personal dashboard</a> takes you to that server's overview page - a quick snapshot before you dive into settings.

## What you see

- Member count and how many are currently online
- Channel count
- Server boost count and the resulting boost level
- Whether the server has Bradycat Premium, and if so, when it started and when it ends

## Activity Log

Every change made through the dashboard (settings saved, modules toggled, etc.) is recorded here, along with who made it and when. Useful if something looks different and you want to know who changed what without having to ask around.

## Removing a user's data

If a member asks you to delete the data the bot has stored about them for your server (tickets, stats, etc.), you can do that from the overview page. This only affects your server - it doesn't touch that person's data on other servers using the bot.

<warning>
This can't be undone. Only use it when you actually mean to delete someone's stored data, not as a way to "reset" something temporarily.
</warning>
