# Minecraft (Only Setup)

<p>This page only covers the setup. What the Minecraft commands can do is explained in <a href="Minecraft.md"/>.</p>

<procedure title="Setting it up with /setup minecraft" id="minecraft-setup">
    <step>
        <p><b>Would you like to enable Minecraft support?</b> - answer <code>yes</code>.</p>
    </step>
    <step>
        <p>That's it - <code>/minecraft</code> can now be used on your server.</p>
    </step>
</procedure>

<note>
<p>Hypixel statistics are no longer available. If the bot also asks about Hypixel support, you can ignore that question.</p>
</note>

<tip>
<p>You can also switch Minecraft support on and off in the dashboard, see <a href="Games-Module.md"/>.</p>
</tip>
