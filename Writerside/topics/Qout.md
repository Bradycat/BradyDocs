# Quote Messages

<p>You can easily activate this feature with <code>/enablefeature Qout Messages</code></p>
<p>When someone posts a link to a Discord message, the bot shows a preview of that message right below it: the author, the text, images and a button to jump to the original message. This way nobody has to click the link to see what it is about.</p>

## Good to know

- Only links to messages from <b>your own server</b> are quoted.
- A message is only quoted if the person who posted the link can read the linked channel. Messages from private threads and age-restricted channels are protected the same way.
- Up to 3 links per message are quoted.
- Mentions in the quoted message are shown but nobody gets pinged.

<tip>
<p>You can also switch quotes on and off in the dashboard under <b>Settings</b>, see <a href="Guild-Settings-and-Modules.md"/>.</p>
</tip>
